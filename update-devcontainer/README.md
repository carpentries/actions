# Update Devcontainer Spec

This action will:
- copy the workbench-devcontainer `.devcontainer` folder into the current lesson repository
- update the .devcontainer/Dockerfile DEVC_IMG arg with any dependency image ref in the org GHCR packages

# Usage

Inputs available:

- `repo` : The current github repository, supplied as ${{ github.repository }}, i.e. org/repo
- `token`: A suitable PAT to adjust the current repo and raise a PR

## Outputs

- `repo-package-ref` : The dependency image package reference from GHCR, e.g. ghcr.io/carpentries/sandpaper-docs-deps
- `date` : The timestamp if the devcontainer directory was created or the Dockerfile DEVC_IMG arg updated

## Example

```yaml
on:
  workflow_dispatch:
    inputs:
      name:
        description: 'Who triggered this build?'
        required: true
        default: 'Maintainer (via GitHub)'

jobs:
  update_devcontainer:
    name: "Update Devcontainer Spec"
    runs-on: ubuntu-latest
    steps:
      - name: "Checkout Repository"
        uses: actions/checkout@v6

      - name: Update Devcontainer
        id: update-devcontainer
        uses: carpentries/actions/update-devcontainer@v1

      - name: Create Devcontainer Pull Request
        id: cdpr
        if: "${{ steps.update-devcontainer.outputs.repo-package-ref }}"
        uses: peter-evans/create-pull-request@v8
        with:
          token: ${{ secrets.SANDPAPER_WORKFLOW }}
          delete-branch: true
          branch: "update-devcontainer"
          branch: "update/devcontainer"
          commit-message: "[actions] update devcontainer to version ${{ steps.update-devcontainer.outputs.repo-package-ref }}"
          title: "Update Devcontainer to Version ${{ steps.update-devcontainer.outputs.repo-package-ref }}"
          body: |
            :robot: This is an automated build

            Set devcontainer spec to: ${{ steps.update-devcontainer.outputs.repo-package-ref }}

            - Auto-generated by [create-pull-request][1] on ${{ steps.update-devcontainer.outputs.date }}

            [1]: https://github.com/carpentries/create-pull-request/tree/main
          labels: "type: workflows"
          draft: false
```
